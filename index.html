BCA Final Year Project Guide & Viva Prep

1. Project Title & Abstract

Title: Social Media Data Analysis and Visualization System
Abstract: This project is a responsive, web-based analytics dashboard designed to ingest, process, aggregate, and visualize multi-platform social media data across Instagram, Facebook, YouTube, LinkedIn, and X (Twitter). The system allows creators, digital marketers, and researchers to track key performance indicators (KPIs), compute engagement rates, and uncover actionable content trends.

2. Core Mathematical Formula

Engagement Rate (%) = [ (Total Likes + Total Comments + Total Shares) / Total Views ] × 100

Interpretation: Measures the proportion of viewers who interacted with the post rather than passively scrolling past it. Benchmarks: ≥ 8% (Viral), 5%–7.9% (High), 2.5%–4.9% (Moderate), < 2.5% (Low).

3. Technology Stack

  • Frontend Structure: Semantic HTML5 elements (<header>, <main>, <section>, <table>).
  • Styling & Layout: Modern Vanilla CSS3 with CSS Custom Properties (Variables), Flexbox, CSS Grid, Glassmorphism, and responsive breakpoints.
  • Client-Side Engine: Vanilla JavaScript (ES6+), DOM Manipulation, Event Listeners, FileReader API for CSV parsing.
  • Data Visualization: Chart.js 4.4.1 for interactive Line, Doughnut, Grouped Bar, and Horizontal Bar charts.
  • Typography & Icons: Google Fonts (Inter, Outfit) and FontAwesome 6.

4. Common Viva Examination Q&A

Q1: How does the CSV file parser work without backend libraries?
A: The system uses JavaScript's native FileReader API to read the text stream from user uploads. A custom parser processes quotations containing commas and escapes, parses header rows, and constructs clean JavaScript objects for state updates.
Q2: How are dynamic filters synchronized with the charts?
A: An application state object (AppState) maintains active filters. Whenever an input changes, applyFilters() produces an updated subset array and triggers updateAllCharts(), which re-aggregates metrics and re-renders Chart.js instances without reloading the browser.
Q3: Can new posts be added at runtime?
A: Yes. The system includes an "Add Post" modal that calculates engagement rates in real time and prepends new entries to the dataset, instantly updating KPI cards, tables, and graphs.
